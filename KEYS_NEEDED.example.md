# API Keys Needed

This file is maintained by the agent. When a feature needs an API key that isn't set, the agent adds a row here automatically.

Fill in the keys in your `.env` file — features activate automatically when the key is present.

---

| Service | Environment Variable | Status | Where to Get It | What It Unlocks |
|---------|---------------------|--------|-----------------|-----------------|
| Example | `EXAMPLE_API_KEY` | ❌ | https://example.com/api | Example feature |

---

## How to add a key

1. Get the key from the URL in the table above
2. Add to your `.env` file: `KEY_NAME=your-value-here`
3. Restart the backend — feature activates automatically
