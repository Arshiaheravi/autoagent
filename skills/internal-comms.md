# Skill: Internal Communications

**When to use**: Writing structured internal updates — status reports, incident reports,
team newsletters, leadership updates, FAQ responses, project updates.

## Communication types

| Type | Use when |
|------|----------|
| 3P Update | Weekly: Progress, Plans, Problems |
| Status Report | Project milestone update |
| Incident Report | Something broke — what happened, why, fix |
| Leadership Update | Executive summary of team activity |
| Project Update | Feature launch, sprint summary |
| FAQ Response | Answering repeated questions once, for reference |
| Team Newsletter | Monthly wins, shoutouts, metrics |

## 3P Update format (most common)

```
## Progress
- [What was completed since last update]

## Plans
- [What is happening next, with owners and dates]

## Problems
- [Blockers, risks, help needed — be specific]
```

## Incident Report format

```
## Summary
[One sentence: what broke, when, who was affected]

## Timeline
- HH:MM — [event]
- HH:MM — [event]
- HH:MM — [resolved]

## Root Cause
[Why it happened]

## Fix
[What was done]

## Prevention
[What changes prevent recurrence]
```

## General rules

- Be specific — "revenue dropped 12%" not "revenue was impacted"
- Lead with impact, not activity
- Owners on every action item (not "the team")
- Problems section: never omit, never sugarcoat

## Project usage

- Weekly agent activity summary to the project owner
- Incident report when a deployment breaks
- Changelog for users when major features ship
